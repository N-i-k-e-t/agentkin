Family of AI Agents.

An independent open-source foundation for small, inspectable agent building blocks.

Why a family?

Each proposed agent has one role. Tools express capabilities. Integrations own external connections. Clear contracts let people reason about the pieces before combining them. That is the design direction; implementation is still early.

What exists today

Contract templates, governance, contribution instructions, launch regression checks, outreach planning and this static website. No commercial reliability claims, paid plans, user totals, affiliations or benchmark scores are implied.

Meet Foa

Foa is our original community companion. The mascot and site were prepared with OpenAI image generation and Codex; asset provenance is recorded in the repository. It represents collaboration, not an autonomous service currently running on this site.
