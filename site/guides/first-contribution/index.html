Your first FOA contribution.

A reproducible path from the repository to a small, signed-off pull request. No paid API key required.

1. Get the source

git clone https://github.com/N-i-k-e-t/foa-agents.git
cd foa-agents
git checkout develop
git switch -c docs/clarify-one-step

For a contribution from your own account, fork first and clone your fork. Keep upstream pointing to the FOA repository; read the branch guide for that setup.

2. Reproduce before editing

python3 -m unittest discover -s scripts -p 'test_launch.py' -v
python3 -m http.server 8000 --directory site

Open http://localhost:8000. The launch tests validate the launch preflight, not agent performance. The contract templates are not a runnable agent.

3. Make one bounded improvement

Correct a reproducible documentation gap or propose a specific contract/test change. Avoid unrelated formatting churn. For substantial features, wait for proposal approval before building.

4. Check and sign off

git diff --check
git add path/to/changed-file
git commit -s -m "docs: clarify one reproducible setup step"
git push origin docs/clarify-one-step

Replace the example path with the real changed file. A sign-off confirms the right to contribute under the license; it is different from a cryptographic signature.

5. Open a PR into develop

Use the PR template, link the issue when relevant and list what you actually tested. Passing checks do not replace human approval. A first PR is welcome even if it needs revisions.
