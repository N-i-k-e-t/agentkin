What an agent declares

A FOA agent has a name, owner, version and a single role. Its contract lists inputs, outputs, tools, integration needs and hand-offs. A YAML contract makes the boundary inspectable; it does not execute a model by itself.

name: your-agent-name
version: 0.1.0
role: one sentence, one job
inputs: [task]
outputs: [result]
tools: [declared-tool]
hands_off_to: [declared-agent]

This excerpt is illustrative. Use the complete repository template for its actual field structure.

Before proposing an agent

  • Describe one concrete user need and a small acceptance test.
  • Keep external access inside an integration and expose it through a tool.
  • Define what happens when a model or tool is unavailable.
  • Include a README, versioned contract and tests using mocks.
  • Declare hand-off inputs and expected outputs explicitly.
