# Code of Conduct

This project follows the Contributor Covenant v2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Short version: be kind, assume good intent, give specific and respectful feedback, and no harassment of any kind. Report problems to niketpatil1624@gmail.com. Maintainers may remove comments, close PRs or ban accounts that break these rules.
