# Student contribution pathway

FOA Agents welcomes voluntary open-source contributions. This is not a paid internship or an employment offer. No placement, certificate or academic credit is promised.

1. Read CONTRIBUTING.md, GOVERNANCE.md and the code of conduct.
2. Choose a small docs, accessibility, testing or contract task that has an available reviewer.
3. Agree acceptance criteria before doing substantial work.
4. Branch from develop, make a signed-off commit and open a PR into develop.
5. Respond to feedback, record what you learned and choose a next task only if you wish.

A PR is pending until a human reviews and merges it. Use mock fixtures and public samples; never put applications, private feedback, email lists or participant records in public Git history. Mentors must opt in before being named.
