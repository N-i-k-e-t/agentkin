# Video Baseline

A launch video of **60 seconds** (plus a 15-second cut for social). Baseline means: the minimum version that is good enough to ship, which others can improve.

## Format

- 1920x1080, 30 fps, MP4 (H.264); also export 1080x1920 vertical for Reels/Shorts
- Burned-in captions (most people watch muted)
- Music: royalty-free or original only; list in `docs/assets/CREDITS.md`
- Voice-over: your own voice or a clearly credited tool

## Script and storyboard (60s)

| Time | Visual | Voice-over | On-screen text |
|---|---|---|---|
| 0:00-0:05 | Logo mark pops in, cream background | "AI agents shouldn't be built alone." | AgentKin |
| 0:05-0:15 | Family group shot, each member waves in | "Meet the family. Each one has one job." | Agents · Tools · Integrations |
| 0:15-0:27 | Architecture diagram animates: integration -> tool -> agent | "Integrations connect. Tools act. Agents decide." | Plug in. Build. Share. |
| 0:27-0:40 | Screen recording: fork, branch, PR | "Pick an issue, open a pull request." | good-first-issue |
| 0:40-0:50 | Live site: contributor wall, star wall, commit feed updating | "Merge, and your name goes live on our site." | Your name. Live. |
| 0:50-0:58 | Conductor character points to camera | "Come build with us." | github.com/N-i-k-e-t/agentkin |
| 0:58-1:00 | End card with logo and URL | | |

15-second cut: 0:00 hook, family, live wall, call to action.

## Production steps

1. Lock script and storyboard
2. Finish logo, 8 characters, architecture diagram, end card (see ASSETS.md)
3. Record screen capture of the real flow and the live site (use the real repo)
4. Record voice-over; clean audio
5. Assemble in any editor (DaVinci Resolve, CapCut, Premiere); simple animation: scale-in, slide, fade
6. Add captions, music at low volume
7. Review on phone with sound off
8. Export, upload to YouTube, embed on the live site hero

## Success baseline

- Hook in first 3 seconds
- Under 60 seconds
- One clear call to action: the repo URL
- Works muted
