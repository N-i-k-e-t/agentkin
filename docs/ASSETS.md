## Production notes

- Draw characters as vector first (SVG) so they scale and recolor for dark mode.
- One shared palette and outline weight across all assets (see CHARACTER_BIBLE.md).
- Keep source files in `docs/assets/src/` and exports in `docs/assets/`.
- Only use art you made or have rights to. If AI-generated, record the tool in `docs/assets/CREDITS.md`.
- Anyone may contribute art; credit goes on the live site like any other contribution.
