# Character Bible (Cartoon Charter)

Rename freely; the structure matters more than the names. All characters are original. Do not base them on existing franchises or mascots.

## Style rules

- **Look:** friendly flat vector cartoon, thick rounded outlines (4 px at 1024), big eyes, simple shapes, one signature accessory each
- **Shape language:** every character is built from one base shape so the family reads as a set
- **Palette (starting point):**
  - Ink outline `#1B1F3B`
  - Cream `#FFF6E5`
  - Coral `#FF6B5E`, Sun `#FFC145`, Mint `#3DDC97`, Sky `#4DA8FF`, Violet `#8B6CFF`
- **Expressions:** neutral, happy, thinking, error, success (min set for the 3 core members)
- **Poses:** front, three-quarter, waving
- **Never:** realistic faces, real people, logos or characters from other brands

## Catchphrases (examples)

- Scout: "Let me look into it."
- Forge: "Give me a tool and a minute."
- Guard: "Keys stay in the vault."
- Conductor: "Everyone, to your parts."

## Charter (how the family behaves)

1. Each member has one job and does it well.
2. Members hand work to each other through clear contracts (`agent.yaml`).
3. Nobody touches secrets they weren't given.
4. Members say when they are unsure.
5. The family grows only by contribution; every new member carries its creator's name.

## Deliverables per character

- Portrait SVG + PNG
- 3 expressions (core members)
- Short bio (50 words) used on the site card
- Voice line for the video
